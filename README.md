# Zero-agent

**Devlog Narrator** — a build-in-public devlog for a single builder. Drop in raw session notes and
optionally pasted `git log` output; a Bedrock-backed generator turns them into a devlog entry held as
a draft for review; approved entries publish to a public reverse-chronological timeline.

Built and shipped on AWS for the AWS [Zero to Shipped](https://builder.aws.com/) hackathon.
